# Autonomous AI Agent (Discord & Telegram)

This project contains a fully functional template for an Autonomous AI Agent that executes voice/text commands, controls browsers via Playwright, and includes self-healing execution blocks powered by Google Gemini API.

## Project Structure
- `main.py`: Entry point for Discord/Telegram bot.
- `agent.py`: Core AI logic and Gemini function calling.
- `automation.py`: Playwright browser automation module.
- `requirements.txt`: Python dependencies.
- `.env.example`: Configuration template for API keys.

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Configure your API keys in `.env`
3. Run the bot: `python main.py`
